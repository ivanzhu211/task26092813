# rigidbody

2D 刚体物理步进库（Go），供上层仿真服务以库形式调用。世界状态全部在内存中，
可保存到本地文件并从文件恢复。单位：米、千克、秒。

## 功能

- 固定步长 1/60 s，重力默认 `(0, -9.81)`（`NewWorld` 传零值 `Vec2` 即默认）。
- 形状：圆、凸多边形（3~8 顶点，顺/逆时针均可；`Box(w,h)` 是便捷矩形）。
  多边形顶点按局部坐标给出，引擎内部平移到以面积质心为原点；
  创建位置与读回位置都指质心。
- 刚体分静态 / 动态。动态刚体质量 0.1~10000 kg，转动惯量按均匀密度由形状算出。
  静态刚体永不移动，静态-静态不碰撞。弹性、摩擦系数均在 [0,1]。
  任何参数非法时整个刚体拒收，世界保持不变。
- 每个世界最多 500 个刚体；id 由引擎按创建顺序从 0 递增分配。
- 接触混合规则：摩擦取两者乘积的平方根，弹性取两者较大值；
  法向接近速度低于 1 m/s 时不反弹。
- 一次 `Step(n)` 推进 1~120 步，超出范围直接拒绝、一步不推进；
  每步接触求解最多迭代 10 轮。

## API 概览

```go
w := rigidbody.NewWorld(rigidbody.Vec2{})        // 默认重力
id, err := w.AddBody(rigidbody.BodyParams{       // 创建刚体
    Shape: rigidbody.Box(1, 1),
    Type:  rigidbody.Dynamic,
    Mass:  1, Friction: 0.6, Restitution: 0.1,
    Position: rigidbody.Vec2{0, 3},
})
err = w.Step(60)                                 // 推进 1 秒
st, err := w.BodyState(id)                       // 位置/转角/线速度/角速度
contacts := w.Contacts()                         // 最近一步的全部接触
err = w.Save("save.bin")                         // 存档（原子写入）
w2, err := rigidbody.Load("save.bin")            // 恢复
```

`Contact` 包含：两个刚体 id（小的在前）、从前者指向后者的单位法线、
穿透深度（贴合为 0）、1 或 2 个世界坐标接触点（平边贴平边 2 个，涉及圆 1 个）。

## 确定性

- 同样的操作序列在两个世界中运行，所有刚体状态逐位相同。
- `Step(120)` 与 120 次 `Step(1)` 结果逐位相同。
- 任意一步后 `Save`，换进程 `Load` 继续跑，与不中断运行逐位相同
  （存档包含求解器热启动状态，格式为固定小端序二进制）。

## 实现要点

- 碰撞检测：圆-圆、圆-多边形（最近点）、多边形-多边形（SAT + 参考面裁剪，
  带参考面选择迟滞以稳定接触流形）。
- 求解器：顺序冲量 + 累计冲量钳制 + 跨步热启动（按接触特征匹配），
  Baumgarte 位置修正（slop 0.005 m），保证高堆叠与金字塔长期稳定。
- 性能：500 刚体大部分互相接触时平均每步约 1~2 ms（上限 16 ms）。

# rigid2d

2D 刚体物理步进库（米/千克/秒），供上层仿真服务以库形式调用，无接口层。
世界状态全在内存中，可序列化为本地文件并逐位恢复。

## 特性

- 圆与凸多边形（3–8 顶点，顺/逆时针均可，自动平移到面积质心）
- 静态/动态刚体，质量 0.1–10000 kg，惯量按均匀密度自动计算
- 固定步长 1/60 s，顺序冲量求解（10 轮迭代 + 热启动），堆叠稳定
- 摩擦混合 √（f₁·f₂)，弹性混合 max(e₁, e₂)，接近速度 < 1 m/s 不反弹
- 确定性：相同操作序列逐位一致；Step(120) ≡ 120×Step(1)；存档恢复后逐位一致

## 用法

```go
w := rigid2d.NewWorld() // 重力默认 (0, -9.81)，步长 1/60

shape, _ := rigid2d.NewPolygon([]rigid2d.Vec2{{-0.5,-0.5},{0.5,-0.5},{0.5,0.5},{-0.5,0.5}})
id, err := w.AddBody(rigid2d.BodyDef{
    Type: rigid2d.Dynamic, Shape: shape,
    Position: rigid2d.Vec2{0, 5}, // 质心位置
    Mass: 1, Friction: 0.6, Restitution: 0.1,
})

err = w.Step(60)          // 一次推进 1–120 步，越界整批拒绝
st, _ := w.GetBodyState(id) // 位置/转角/线速度/角速度
contacts := w.Contacts()  // 最近一步的全部接触

w.SaveToFile("save.json") // 存档
w2, _ := rigid2d.LoadFromFile("save.json") // 恢复后继续跑，逐位一致
```

## 限制

- 每世界最多 500 个刚体，超出拒收
- 任何参数不合法，整个刚体拒收，世界保持不变
- 静态刚体之间不碰撞
